# Tecnologias Utilizadas no Desenvolvimento do Site

Este documento descreve as principais tecnologias, ferramentas e serviços utilizados no desenvolvimento da interface web.

## Front-end

| Tecnologia | Finalidade |
|------------|-----------|
| HTML5 | Estrutura |
| CSS3 | Estilização e layout |
| JavaScript | Interatividade e lógica |
| React | Construção da interface |

## Back-end

| Tecnologia | Finalidade |
|------------|-----------|
| Node.js| Processamento do servidor |

## APIs e Integrações
 
| API | Finalidade |
|-----|-----------|
| API própria (REST) | Recebe os comandos lidos pelo site e os processa no servidor |
| Gamepad API (Web API do navegador) | Leitura de controles/gamepads conectados, com detecção de botões e analógicos para controlar a interface ou o jogo |


## Ferramentas de Desenvolvimento

- **Git / GitHub** — controle de versão e colaboração
- **VS Code** — editor de código
- **npm** — gerenciamento de pacotes

## Como Executar a Interface

```bash
# Clonar o repositório
git clone https://github.com/Matheus-S-Camargo/PS_Titans-Gp3

# Abrir a pasta da Interface
cd interface
cd site

# Instalar dependências
npm install

# Iniciar o servidor de desenvolvimento
npm run dev
```
